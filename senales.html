≈50% = lanzar una moneda. Con comisiones y spread se necesita más de ~53-55% sostenido para no perder dinero, y un backtest pasado no garantiza nada.

La regla (transparente)

  1. EMA9 vs EMA21 del cierre: EMA9 > EMA21 → +1, < → −1.
  2. RSI14: > 55 → +1, < 45 → −1, entre medio → 0.
  3. Ratio taker-buy de la última vela cerrada (volumen comprador agresivo / volumen): > 0.52 → +1, < 0.48 → −1, si no 0 (Coinbase no da este dato → 0).
  4. Suma > 0 → SUBE; < 0 → BAJA; empate → dirección de la última vela cerrada.

Se calcula con velas cerradas al abrir cada vela y predice si esa vela cerrará por encima (SUBE) o por debajo (BAJA) de su apertura. Se califica sola al cerrar. Velas con cierre = apertura no cuentan. Código: senales_rule.js.
